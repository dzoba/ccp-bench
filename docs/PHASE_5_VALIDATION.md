# Phase 5 validation

The public bank has 181 Simplified Chinese machine translations and 26 Traditional Chinese machine translations for Taiwan/Hong Kong. Reported Claude translation cost was approximately $0.1023. Original English wording, rubric content, source provenance, and version history are preserved. Human translation review remains pending.

A locally prepared private bank contains 75 unpublished paraphrase drafts plus three locally generated canary decoys, covering 78/259 combined items (30.1%). All 78 have Simplified Chinese; 11 Taiwan/Hong Kong items also have Traditional Chinese. The prompts share public topics/rubrics, so this is not unseen-topic evidence. Private translations were authored in the existing OpenAI coding session after a separate endpoint upload was rejected. The GitHub repository is verified private and owned by the authenticated maintainer, but uploading its payload awaits explicit approval from automatic review.

The evaluation loader reads this separate bank through `HELDOUT_REPO_PATH`. The public loader rejects held-out items. A deterministic category/type split suggestion is available without moving or retiring public data automatically.

Local integration run `heldout-smoke-v2`: 1,110 mock samples, 2,220 valid mock verdicts, zero errors or exclusions. Held-out items contribute to aggregates. Publication dry run produced 186 public JSON files (1,524,727 bytes) and passed hidden-ID, prompt, and canary scans. This validates mechanics only and was not deployed as model research. The prior v1 run is preserved: it caught a short translated prompt overlapping the public bank and a mock label-priority issue on decoys. Both were corrected without weakening the leak check or discarding the original evidence.

Automated tests cover the full hidden-item run/judge/score/export path, explicit review import and translation-only compatibility, stratified split determinism, and divergence mathematics. Real private prompts and canaries are never fixtures in public tests.

Discovery CLI implements public topic generation, bilingual four-model pilots, embedding deduplication, cross-cohort cosine distance, and a separate material-claims disagreement judgment. Candidate outputs remain ignored and require human annotation before entering the bank. The bounded live demonstration completed: eight candidates generated, seven ranked, one retained as incomplete/unranked, with $0.2472356065 reported spend. No candidate was added to the bank automatically.

The live bilingual pilot `pilot-bilingual-v1` completed 132 responses across three models and 20 public items: English and Simplified Chinese for all items, Traditional Chinese for four Taiwan/Hong Kong items. Response generation reported $0.06404808795; judging reported $0.6730446. A separately recorded interrupted in-flight request may have unreported billing. Of 262 judge records, 257 are valid and five failed after retries (four semantic/schema validation failures, one incomplete verdict). There are 28 review cases. Scoring includes 126 model-language-item observations and excludes one API-filtered response plus five responses missing a valid judge pair. No response was truncated.

Export `0.1.0-dev-pilot-bilingual-v1-initial-1a0268e7a2e1` contains 187 files (1,145,461 bytes), passes schema and held-out leak scans, and remains explicitly provisional: human calibration is pending, there are no held-out research samples, and at least one model exceeds the 2% judge-error threshold. Failed judgments remain in coverage rather than becoming inferred labels. The bilingual composite is now populated; the observed Kimi result remains different from the anticipated Western-model pattern. The small draft-item pilot does not establish a general model ranking.

The static review page and its original dataset fingerprint remain valid after translation additions. Incremental JSON imports preserve prior decisions and accept later corrections; no real human review has been imported. Concurrent judging drains in-flight requests on interruption and resumes completed pairs without duplication. The local suite passes 45 unit tests; CI additionally exercises four Firestore emulator cases.

The bilingual version is deployed at https://ccp-bench-staging.web.app. Its raw run artifacts, failed judgments, and interruption audit are archived in the existing private staging bucket. Workspace lint and the staging production build pass.
